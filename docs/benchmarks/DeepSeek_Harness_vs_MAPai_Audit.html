Subagent Lifecycle: Spawn vs. In-Process Context Forking
🛡 3-Tier Process Teardown & Anti-Leak SLA

The harness incorporates a deterministic shutdown lifecycle inside subagent-acp:

1. Graceful EOF transmission to child stdin.
2. SIGTERM grace window allowing in-flight file buffers to flush.
3. Hard SIGKILL fallback with aggregated diagnostic telemetry.

Eliminates rogue child daemon leakage on Windows, guaranteeing zero zombie processes during parallel multi-agent test runs.

💻 Windows ConPTY & Native Addon Isolation

Unlike typical Unix-first agent runners, dsh bundles precompiled ConPTY 1.25 Windows DLLs directly into @deepseek-ai/dsh-pwsh-sandbox:

• Native pseudo-terminal emulation (PTY) on Windows 11.
• Full ANSI color palette & interactive terminal cursor tracking.
• Prevents command hanging on prompts requiring interactive input.

Seamlessly handles both interactive shell commands and headless batch execution.
