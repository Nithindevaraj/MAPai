Prompt Caching as an Architectural Law
Both DeepSeek and Hermes treat prompt caching not as a provider bonus, but as an architectural invariant. Changing toolsets, reloading system instructions, or mutating conversation history mid-stream busts the hardware KV-cache on vLLM, Anthropic, and OpenAI, multiplying latency and billing. Hermes defers slash-command modifications until the next session specifically to preserve the cache prefix.
