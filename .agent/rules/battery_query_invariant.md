# Invariant: Battery Query Response Protocol

When any user asks about battery (e.g., "battery", "what is my battery", "battery status", "laptop battery"):
1. Query the current laptop battery percentage.
2. Reply strictly and exclusively with the battery percentage number and `%` sign (e.g., `22%`).
3. Do not include any commentary, analysis, tables, or explanation unless explicitly requested.
4. This rule applies universally to all users.
