# Invariant: Minimal Text Generation for Basic Queries

1. For basic inquiries, single-metric queries, status checks, confirmations, and simple questions, generate minimal text (direct answer only, no unsolicited explanations or boilerplate).
2. Avoid conversational filler, preambles, or postambles when the requested information is basic.
3. Reserve detailed breakdowns and artifacts for complex architectural tasks, code reviews, and explicit requests for analysis.
